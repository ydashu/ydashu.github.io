建站 Hugo

hugo建站流程-linux

2024-12-24

hugo:The world’s fastest framework for building websites

  • 自称是最快的建站框架
  • 静态网站，hugo比hexo快
  • 网站速度hugo > hexo > (wordpresss ? shopify)
  • 可以零成本搭建（本地计算机 + github page等免费host + github action自动触发）
  • 官网：gohugo.io

下面以 ubuntu本地计算机 + github page + github action展示建站流程

安装hugo 

1
2

sudo apt update
sudo apt install hugo

创建站点 

1
2

cd Desktop
hugo new site ydashu

启动hugo 

1
2

cd ydashu
hugo server
  • 地址通常是 localhost:1313 。如果页面显示“Page not found”，说明此前的所有配置都是正常无误的。
  • 具体的hugo命令参考官网hugo conmands

配置主题

Hugo 默认是没有主题的，需要到 官网 去下载主题。我使用的主题是 Jimmy Cai 创作的 Stack 主题。接下来的部分内容会以此主题为例。

下载Stack主题

hugo-theme-stack

文件调整

  • 将主题下载完成后重命名为hugo-theme-stack并解压至 themes 文件夹中，将ydashu/themes/hugo-theme-stack/exampleSite/ 文件夹中 content 和hugo.yaml 复制到ydashu/中，并删掉原来的 hugo.toml 和 Content/post/rich-content （rich-content中有需要梯子的链接，hugo server会出现错误），避免出现不兼容的错误。
  • 修改 hugo.yaml 中的 theme 选项，将其修改为theme: hugo-theme-stack

检查网站

  • 启动hugo server
  • 检查网址localhost:1313是否是正常的stack主题

SSH连接github

git push 前因当通过SSH配置连接

  • 检查现有的 SSH 密钥 
    1

    ls -al ~/.ssh
    -如果你看到 id_rsa.pub、id_ed25519.pub 或类似的 .pub 结尾的文件，说明你可能已经有一个公钥
    • 如果没有则使用以下命令生成 
      1

      ssh-keygen
  • 生成一个新的 SSH 密钥对 (如果不存在或想重新生成) 
    1

    ssh-keygen -t ed25519 -C "your_email@example.com"
    • your_email@example.com 替换为你的 GitHub 注册邮箱
    • 系统会提示你选择保存密钥文件的位置（默认是 ~/.ssh/id_ed25519）。直接按 Enter 接受默认位置即可
    • 系统会提示你输入一个密码短语 (passphrase)。这是一个可选的密码，用于加密你的私钥。如果你设置了，每次使用 SSH 密钥时都需要输入它。为了方便，可以留空（直接按 Enter），但为了安全起见，也可以设置
  • 将 SSH 公钥添加到你的 GitHub 账户
    • 复制你的 SSH 公钥 
      1

      cat ~/.ssh/id_ed25519.pub
      • 这将显示你的公钥内容。复制所有内容，从 ssh-ed25519 开始到你的邮箱地址结束
    • 登录 GitHub
    • Settings/SHH and GPG keys/New SSH key
      • Title: 例如 My Ubuntu Laptop SSH Key
      • Key: 复制的公钥内容粘贴到这个文本框中
    • Add SSH key
  • 将 SSH 私钥添加到 ssh-agent
    • 启动 ssh-agent 
      1

      eval "$(ssh-agent -s)"
    • 将你的私钥添加到 ssh-agent 
      1

      ssh-add ~/.ssh/id_ed25519
  • 测试 SSH 连接 
    1

    ssh -T git@github.com

Github action自动部署

如果没有进行自动部署，我们每次更新博客时，都需要在已经搭建好环境的电脑上进行、都要手动进行 Hugo 编译，再推送 Public 文件夹到 Github 仓库。自动部署让整个写作+发布流程更加快捷，相当于把Hogo编译推送public文件夹的工作交给了github action。

新建Github仓库

新建一个 Github 仓库，仓库名为 ydashu_main，权限设置为 private.

创建github账号token

  • 点击github右上角账号界面中的Settings/Developer Settings/Personal access tokens/Tokens(classic)或者直接点开下面链接 https://github.com/settings/tokens/new
  • 点击Generate new token (classic)
    • Note: hugo部署
    • Expiration: No expiration
    • Select scopes:
      • repo
      • workflow
  • 点击Generate token
  • 保存好token，这个token只会出现一次，假设是hugo_deploy_token

name: deploy

# 代码提交到main分支时触发github action
on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-24.04 
    # 原始值为ubuntu-latest，（Ubuntu使用latest会报warn，提示最新支持版本已经改为Ubuntu24.04
    steps:
        - name: Checkout
          uses: actions/checkout@v4
          with:
              fetch-depth: 0

        - name: Setup Hugo
          uses: peaceiris/actions-hugo@v3
          with:
              hugo-version: "latest"
              extended: true

        - name: Build Web
          run: hugo -D

        - name: Deploy Web
          uses: peaceiris/actions-gh-pages@v4
          with:
              PERSONAL_TOKEN: ${{ secrets.你的 Token 变量名 }}
              EXTERNAL_REPOSITORY: ydashu/ydashu.github.io
              PUBLISH_BRANCH: main
              PUBLISH_DIR: ./public
              commit_message: auto deploy
